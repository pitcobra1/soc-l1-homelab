# SOC l1 Hhmelab

A hands-on cybersecurity homelab designed to develop practical skills for **SOC Analyst L1 / Junior Cybersecurity Analyst** roles.

## Project Objective

The goal of this project is to build a controlled environment where I can practice:

* Security monitoring
* Log analysis
* Alert triage
* Incident investigation
* Windows and Linux security
* Network analysis
* SIEM fundamentals
* SOC documentation and escalation workflows

## Lab Environment

### Host Machine

* Windows
* Intel Core i5-12400
* 16 GB RAM
* VirtualBox

### Virtual Machines

**Ubuntu**

* Status: In progress
* Purpose: Linux administration, security monitoring, log analysis, and server-side security practice

**Kali Linux**

* Status: Planned
* Purpose: Generate controlled security events and network activity inside the lab

**Windows Lab Machine**

* Status: Planned
* Purpose: Windows Event Logs, authentication monitoring, PowerShell activity, endpoint investigation, and security event analysis

### Security Monitoring

A SIEM/security monitoring solution will be added as the environment develops.

Planned areas of study include:

* Centralized log collection
* Authentication monitoring
* Suspicious process detection
* Network activity
* Alert investigation
* Event correlation

## Planned SOC Investigations

The lab will be used to simulate and investigate scenarios such as:

1. Multiple failed login attempts
2. Successful authentication after repeated failures
3. Suspicious PowerShell activity
4. Privilege-related events
5. Suspicious network connections
6. Potential lateral movement
7. Security alert triage and escalation

Each investigation will be documented with the evidence collected, analysis performed, conclusions, and recommended SOC actions.
